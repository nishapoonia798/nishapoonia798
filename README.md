## 🚀 What I've Built

### Automated Network Policy Pipeline
`Jenkins` `Ansible` `FortiManager` `Python` `Bash`
Pipeline that automates NAT rule creation, static route provisioning, and FortiManager firmware upgrades, with pre/post validation and auto-rollback. Cut deployment time by ~70%.

### Multi-Cloud IaC Automation
`Terraform` `AWS` `GCP` `Ansible` `Python`
Reusable Terraform modules for EC2, VPC, static routes, NCC, and firewall rules across AWS and GCP. Setup time dropped from hours to under 10 minutes, with remote state and IAM governance.

### Observability & Vulnerability Alerting Stack
`Prometheus` `Grafana` `Alertmanager` `Ansible` `Python`
Deployed metrics, dashboards, and alerting across Linux VMs via Ansible. Reduced on-call response time by 40%.

### GCLB Monitoring: BigQuery + Looker Dashboard
`GCP APIs` `Python` `BigQuery` `Looker Studio`
Python pipeline that fetches load balancer metrics via GCP APIs, stores them in BigQuery, and serves live Looker Studio dashboards for traffic, backend health, latency, and error rates.
